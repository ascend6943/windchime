WINDCHIME 1.0.0

See README.md for features, desktop requirements, privacy, building, checks,
installation, and removal. See RELEASE_NOTES.md for the first public release.

Install: extract the release, enter its windchime folder, and run ./install.sh.
Open Windchime from your application launcher. Closing its window keeps it in
its tray. Ctrl+Alt+W is the suggested pause shortcut; use Set pause shortcut to
configure it through your desktop.

Uninstall as your normal desktop user: /opt/windchime/uninstall.sh

A global physical keyboard reader cannot recognize password fields. Pause
before sensitive typing. Typed text is never assembled or stored.
